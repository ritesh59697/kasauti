# Kasauti web

Vite + React + wagmi/RainbowKit. `index.html` is the landing page and `app.html` the trade app (served at `/app`). `deploy.html` is a local-only page for deploying from a browser wallet; it is left out of the production build.

```bash
cp .env.example .env
npm install
npm run dev
```

See the [root README](../README.md).
